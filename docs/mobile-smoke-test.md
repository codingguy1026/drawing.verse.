# 모바일 레이아웃 10분 점검표

목적: 데스크톱 중심 레이아웃이 휴대전화에서 가로 스크롤, 메뉴 가림, 터치 불편을 일으키지 않는지 빠르게 확인한다.

## 준비
- 개발 서버: `npm run dev`
- 브라우저 개발자 도구의 기기 모드에서 너비 **320px / 375px / 768px** 각각 확인한다.
- 아래 항목은 **직접 확인 후** 체크한다. 미체크는 결함 확정이 아니라 미검증이다.

## 홈에서 먼저 확인
- [ ] 화면 전체에 불필요한 가로 스크롤이 없다.
- [ ] 내비게이션이 본문을 가리거나 화면 밖으로 밀려나지 않는다.
- [ ] 첫 화면에서 주요 콘텐츠와 이동 경로를 알아볼 수 있다.
- [ ] 긴 제목·영문 URL·버튼 문구가 레이아웃을 깨뜨리지 않는다.
- [ ] 링크와 버튼을 손가락으로 구별해서 누를 수 있다.
- [ ] 320px에서 화면을 확대하지 않고 본문을 읽을 수 있다.
